# Night City, In Order

An interactive 3D timeline that walks through the story of the Cyberpunk 2077 universe in chronological order:

1. **Prologue (2023)**: Johnny Silverhand and the Arasaka Tower raid
2. **Cyberpunk: Edgerunners (2075–2076)**: anime, season one
3. **Cyberpunk 2077 (2077)**: the game, with Phantom Liberty placed mid-story
4. **Cyberpunk: Edgerunners 2 (c. 2078)**: anime, season two

Full spoilers for all of the above. The intro screen has an option to blur the Edgerunners 2 chapters.

## Using it

- Scroll or use the arrow keys to travel between the 21 stops
- Drag to look around
- "Auto tour" rides through hands-free
- Tap a name under "Who's here" for an optional character card

## Running it

It is a single `index.html` with no build step. Open it in a browser, or enable GitHub Pages for this repo (Settings → Pages → deploy from the `main` branch) to host it.

Three.js r128 loads from cdnjs and fonts load from Google Fonts, so it needs an internet connection.
